# 入道雲サーチ ローディングの雲を Claude Code で作る

作成日: 2026-10-29

## 用意するもの

このフォルダの2つのファイルを、リポジトリの docs/nyudogumo/loading/ に置いてから Claude Code を開きます。作業するブランチは feature/new-ui です。

- cloud_loading.html … ブラウザで開くと動きが見られる見本。Claude Code はこれを正として形と動きを合わせます。
- cloud_loading.dart … 同じ動きを Flutter で書いた参考コード。そのまま使えるように書いてありますが、色をテーマに移すなど、リポジトリの書き方に合わせて直してもらいます。

## おすすめの作り方

Flutter に最初から入っている CustomPainter と AnimationController だけで作るのがおすすめです。雲は15個の丸を重ねて描いているだけなので、計算が軽く、パッケージを足す必要がありません。色や速さもコードの数字を変えるだけで調整できます。

Lottie や Rive を使う方法もありますが、どちらもパッケージとアニメーションのファイルが増え、形を直したいときに専用のツールで作り直すことになります。GIF や動画は、背景の青のグラデーションの上で縁がきれいに出ず、ファイルも重くなります。今回の雲は形が単純なので、どちらも使うほどではありません。

なお、アプリを押してすぐに出る起動画面 (ネイティブのスプラッシュ) は、仕組み上アニメーションできません。起動画面のあとに出る Flutter の最初の画面で、この雲を出す形になります。起動画面の背景色を読み込み画面と同じ灰色 (#EFF2F7) にそろえておくと、切り替わりが目立ちません。

## 貼る指示文

ここから下を、そのまま Claude Code に貼ってください。

```
ローディング中に出す「雲がもくもく湧く」アニメーションを追加したいです。feature/new-ui ブランチで作業してください。

見本は docs/nyudogumo/loading/cloud_loading.html です(ブラウザで開くと動きます)。同じ計算を Flutter で書いた参考コードが docs/nyudogumo/loading/cloud_loading.dart にあります。

やってほしいこと:
1. 参考コードをもとに、雲のウィジェットを共通部品の置き場に追加する。作り方は CustomPainter と AnimationController だけにして、Lottie などのパッケージは足さない。
2. 色は画面に直接書かず、テーマにまとめる。通常は背景 #EFF2F7・雲 #BCD0EC・影 #8DA8D2・文字 #8A93A0。ダークモードは背景 #1A1F29・雲 #4B6290・影 #33456B・文字 #7D8590。
3. 読み込み画面は、灰色の背景の真ん中に一辺64の雲を1つだけ置き、すぐ下に小さく「読み込み中」(12ポイント)と出すだけのシンプルなものにする。アプリ名やグラデーションは出さない。見本の画面に合わせる。
4. 起動したあと最初のデータを待つあいだと、ホームで更新しているあいだの両方で、この読み込み画面を使う。
5. データが届いたら、アニメーションの途中でもすぐに次の画面へ進む。アニメーションを見せるために待たせない。
6. 端末の設定で動きを減らしている人(MediaQuery の disableAnimations)には、止まった雲だけを出す。
7. 雲の絵は読み上げの対象から外し、文字の「読み込んでいます」だけが読み上げられるようにする。

書き始める前に、どのファイルを足して、どの画面のどこを変えるかの計画を見せてください。終わったら flutter analyze とテストを通し、雲のウィジェットが表示されること・動きを減らす設定で止まることを確かめるウィジェットテストも足してください。最後に、アプリで確かめる方法を短く教えてください。
```

## 動きを直したいとき

見本の HTML と Dart のコードは同じ数字で動いています。もう少しゆっくりにしたいときは「くり返しの2.4秒を3秒に」、雲を大きくしたいときは「雲の一辺を64から80に」のように、数字で頼むと伝わりやすいです。形を変えたいときは、この会話で HTML の見本を直してから、同じファイルを置き直して頼むのが確実です。
