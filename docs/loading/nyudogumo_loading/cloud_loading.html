雲がもくもく湧くローディング

うすい灰色の背景の真ん中に、小さな雲だけをぽつんと置きました。雲は下から順に湧き上がったあと、同じ順番で下から上へ、ぽこぽことふくらむ動きをくり返します。左が通常、右は端末をダークモードにしているときです。

動きのしくみ

雲は15個の丸でできています。最初の1.4秒で、下の段の丸から順に、少し大きくなってから落ち着くように現れます。そのあとは2.4秒ごとに、同じ順番で下の段から丸がぽこっとふくらんでは戻ります。上の段ほど少し大きくふくらみます。

雲の一辺は64、色はうすい青にして、目立ちすぎないようにしています。

アプリでは Flutter の CustomPainter と AnimationController だけで作れるので、画像やアニメーション用の部品を追加する必要はありません。端末の設定で動きを減らしている人には、動かない雲だけを出します。
